# Image credits

The self-hosted travel photographs in this directory are sourced from Unsplash.
Missing prototype images are downloaded from:

`https://images.unsplash.com/photo-{id}?w=1800&q=75&auto=format&fit=crop`

Run `scripts/fetch-assets.ps1` on Windows or `scripts/fetch-assets.sh` on
Unix-like systems to fetch any missing files. Existing images are not
overwritten.
